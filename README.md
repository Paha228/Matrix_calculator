# Matrix Calculator

## Описание задачи
Библиотека на C++17 для работы с матрицами: создание, освобождение,
сложение, умножение, вывод, создание из массива.
**Индивидуальное задание №3:** создание единичной матрицы (`matrix_identity`).

## Сборка и запуск
\`\`\`
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/matrix_calculator
\`\`\`

## Обработка ошибок
Все некорректные аргументы (нулевой/отрицательный размер, несовместимые
матрицы) → исключение `std::invalid_argument`.
Ошибки аллокации → `std::bad_alloc`.

## Реализованные функции
| Функция | Назначение |
|---|---|
| `create_matrix` | Создание матрицы rows×cols, нули |
| `free_matrix` | Освобождение памяти |
| `matrix_add` | Сложение |
| `matrix_multiply` | Умножение |
| `print_matrix` | Вывод (с сокращением больших матриц) |
| `matrix_from_array` | Создание из одномерного массива |
| **`matrix_identity`** | **Единичная матрица size×size (задание №3)** |

## Проверяемые сценарии
См. `tests/test_matrix.cpp`:
- нормальные случаи (создание, сложение, умножение, identity 5×5);
- граничные (1×1, вектор×вектор, identity(1));
- некорректный ввод (размер <= 0, несовместимые размеры).
